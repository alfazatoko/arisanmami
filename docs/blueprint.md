# **App Name**: MamaArisan

## Core Features:

- Arisan Group Setup: Easily create and configure new arisan groups, defining parameters such as group name, contribution amount, number of participants, and drawing frequency.
- Participant Enrollment: Add, edit, and remove participants for each arisan group, ensuring accurate member management.
- Contribution Tracking: Record and view payments for each round from individual participants, keeping track of who has contributed.
- Automated Drawing Tool: An AI-powered tool to fairly select the next arisan winner from eligible participants, helping ensure equitable turns over time and providing an impartial draw.
- Round History View: Access a clear overview of past winners, the current collection status, and remaining participants for upcoming draws.
- Reminder Generation Tool: A tool to generate personalized reminder messages for participants regarding upcoming contributions or drawing events, facilitating communication within the group.

## Style Guidelines:

- Primary color: A warm, inviting terracotta (#DB764F), conveying community and friendliness in a light scheme.
- Background color: A subtle, desaturated off-white (#F7F0EC) for a clean and comfortable feel.
- Accent color: A soft, rosy pink (#EC93B4) analogous to the primary, adding a gentle touch of vibrancy for key actions.
- All text: 'PT Sans' (humanist sans-serif) for its modern yet warm and legible qualities, suitable for both headlines and body text.
- Clean, friendly, and community-oriented line-art icons, providing visual clarity and a welcoming aesthetic.
- An intuitive and mobile-responsive layout featuring card-based designs for groups and clear tabular displays for participant contributions.
- Subtle and smooth transitions for page navigation and drawing announcements, enhancing the user experience without being distracting.
